# BrunoOS 98 — Interactive Portfolio

> A fully interactive Windows 98-style personal portfolio built from scratch with vanilla HTML, CSS, and JavaScript. No frameworks and no libraries.

---

## Features

- **Draggable windows** — every section opens as a real, movable Win98 window
- **Working taskbar** — with a Start menu, clock, and active window buttons
- **Desktop icons** — draggable, selectable, double-click to open
- **Start menu** — fully functional with BrunoOS 98 branding
- **Minesweeper** — fully playable with timer, flag system, flood-fill reveal, and win/lose states
- **MS Paint clone** — draw with pencil, line, rectangle, eraser, and a full color palette
- **Windows 98 startup sound** — plays on load
- **Shutdown dialog** — with blocked messages
- **Recycle Bin** — empty, obviously
- **Custom cursor** — authentic Win98 `.cur` cursor files
- **CV download** — direct PDF download from the desktop icon
- **Contact window** — animated "Establishing connection..." progress bars for LinkedIn and GitHub
- **Skills & Languages explorer** — Windows Explorer-style table with honest proficiency levels

---

## Built With

| Technology | Usage |
|---|---|
| HTML5 | Structure and all window content |
| CSS3 | Win98 design system, animations, layout |
| Vanilla JavaScript | Window management, drag & drop, Minesweeper, Paint, clock |
| Canvas API | MS Paint drawing engine |
| Web Audio API | Startup sound |
| Clipboard API | Email copy button |
